# CG Plumbing

Professional plumbing services website built with modern web technologies.

## Overview

CG Plumbing is a responsive web application for a plumbing company, featuring a modern design with service information, contact details, and professional branding.

## Features

- Responsive design for all devices
- Professional hero section with company branding
- Service information display
- Contact information with phone and QR code
- Navigation menu
- Modern UI with custom styling

## Tech Stack

- **Framework:** React 19
- **Language:** TypeScript
- **Build Tool:** Vite 7
- **Styling:** Tailwind CSS 4
- **Routing:** React Router DOM 7
- **Deployment:** Vercel

## Getting Started

### Prerequisites

- Node.js (latest LTS version)
- npm or bun

### Installation

```bash
# Clone the repository
cd cg-plumbing-project/CGPlumbing

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── assets/          # Fonts and images
├── components/      # React components
├── App.tsx          # Main application component
├── index.css        # Global styles
└── main.tsx         # Application entry point
```

## Deployment

The project is configured for deployment on Vercel. The `vercel.json` configuration file is included.
